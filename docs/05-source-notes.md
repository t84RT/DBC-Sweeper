## 二、辟谣：不要照做的"教程"

### 1. CSDN「问」上的大白菜去广告回答

特征：页面底部有「GEO 优化 / AI 选题 / 数据监测 / 一键分发」推广位；回答结构工整但空泛；
给出的键值、域名、进程名在别处查不到；动辄 `reg delete /f` + `del /f`。

危害：那些 `reg delete /f` 会删掉真实存在的系统键；`del /f` 指向的路径可能不存在，
但一旦存在就是系统文件。**本工具未采信其中任何一条。**

### 2. "删掉 `System32.7z` 就一劳永逸"

部分对，但要说清适用范围：

- 对**还没装的系统**：有效。删掉后 PE 里不再生成 `NUML0CK.exe`。
- 对**已经装好的系统**：无效。软件已经装了，删 U 盘里的文件不会卸载它们。
- 而且要处理**所有** PE 镜像（Win2003PE / Win8PE / Win10PE / UEFI 版），只改一个不彻底。

### 3. "把 `.NET Framework NGEN` 任务删掉"

逆向记录里出现过它的 TaskCache GUID（`{9903F86D-…}`），但那就是**系统自带的 NGEN 维护任务**。
把它当 IOC 会大面积误报，删了可能影响 .NET 程序启动。**不要动。**

### 4. "用 XX 一键清理大师深度清理注册表"

注册表误删的代价是重装系统，而收益是"可能"少几个残留键。
正确做法：只删你**能指出它属于哪个软件**的键，删前导出 `.reg`。

### 5. "装个 360 就能防住"

被推广装的 360 本身就是推广目标之一，而且它会**默认锁定浏览器首页**——
这正是"改了设置又变回去"的常见原因之一。

## 三、可信度自检方法

看到一条"大白菜 IOC"时，问三个问题：

1. **能在两个独立来源里找到吗？** 只有一处、且那处带推广位 → 大概率编的。
2. **它是"行为描述"还是"具体路径/键值"？** 只有行为描述无法验证；具体路径要能在自己机器上找到。
3. **它建议的动作可逆吗？** 让你直接 `reg delete /f`、`del /f`、`takeown` 全盘的，一律先怀疑。

## 四、法律与边界

- 大白菜的推广行为在**用户协议层面**通常有告知（安装时勾选项），所以严格说不是"未授权入侵"。
  但 PE 阶段删除第三方安全软件（火绒报告所述）已经越界。
- 本文档与工具的目的是**用户清理自己机器上的不需要的软件与设置**，不涉及绕过授权、破解或攻击他人系统。
- 重做启动盘、修改自己 U 盘里的 PE 镜像，属于对自己财产的处置。

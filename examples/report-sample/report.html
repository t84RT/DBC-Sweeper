五、这套东西是怎么进来的

阶段具体行为落地痕迹
制作 U 盘默认勾选「赞助商主页 / 绿色软件」，推广配置写进 PE 镜像制作工具个性设置、HKLM\SOFTWARE\DaBaiCai
PE 启动X:\windows\Packages\System32.7z、PF.7z 解压出部署程序 NUML0CK.EXEPE 内 System32、U 盘 \PE\DBC8x64.ISO
释放镜像在 C:\Windows\<随机名>\ 放随机名启动器 + 十余个加密 .img/.ext 安装包随机名目录、数百 MB 分包
无人值守写 Panther\unattend.xml：启用 Administrator、关 UAC、首次登录自动拉起启动器RunSynchronousCommand、ConsentPromptBehaviorAdmin=0
首次进桌面静默装 360 全家桶 / 2345 / 腾讯视频 / 爱奇艺 / 老黄历 / WPS，改主页与收藏夹，启动器自删安装日期与会话/配置里的推广域名
持续复发计划任务、WMI 订阅、组策略键、安全软件「主页锁定」、浏览器会话恢复本报告 B / C / D 层
关键结论：用微软原版纯净 ISO 也挡不住——植入发生在 PE 阶段、系统首次启动之前。所以「装完再删」只能治标，去源头重做启动盘 / 换微PE、优启通 + 官方 ISO才治本。

六、工具不做、但你应该做的

  1. 恢复 UAC：EnableLUA=1、ConsentPromptBehaviorAdmin=5，改前导出注册表键。
  2. 改回默认应用：.html 与 http/https 若指向 360seURL，走「设置 → 应用 → 默认应用」改回，别手改注册表（UserChoice 有哈希校验）。
  3. 卸软件走正规卸载：设置 → 应用 → 按安装日期排序，卸完用 Geek Uninstaller / Revo 扫残留。
  4. 清旧系统：设置 → 系统 → 存储 → 临时文件 → 删除以前版本的 Windows。不要手删 Windows.old。
  5. 浏览器内再收一遍：edge://settings/startHomeNTP 选「打开新标签页」；edge://settings/content/all 搜推广域名删站点数据。
  6. 治本：大白菜制作器 → 个性设置 → 支持我们 → 取消全部推广 → 保存设置 → 重新制作；或直接换微PE / 优启通。

七、工具边界

只做可逆动作：改名、移动、注释、禁用、导出备份。移入隔离区不等于释放空间，确认无误后手动清空隔离目录才省空间。

绝不自动处理：unattend.xml、C:\Windows\<随机名>、系统服务与驱动、UAC、组策略键、hosts 之外的系统文件、Windows.old、用户账户、代理设置。这些要么在系统目录、要么可能是你自己的开发/调试环境配置。

白名单保护：PlatformIO、Arduino、Python、VS Code、CH340/CP210x/FTDI 驱动等开发工具不会被判为推广软件。

已知不完美：随机名启发式可能漏判新版变体；浏览器 Secure Preferences 受 MAC 保护，工具不碰；会话文件在浏览器运行时会被独占，必须先完全退出浏览器再修。
